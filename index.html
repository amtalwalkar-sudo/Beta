Cloud Backup (BETA slot — separate from Stable)

Checking last cloud backup…
Backs up to your own Firebase project — no sign-in needed. Overwrites the previous cloud backup each time (only the latest copy is kept). Restoring replaces whatever's on this device, so it also takes a local safety snapshot first, same as Import.

Export / Import Data

Saves to your phone's regular Downloads folder — open the Files app → Downloads to find , then move it to Drive/Dropbox/email yourself from there.
"Try Direct Share Instead" attempts to open your phone's native share sheet directly to Drive/Gmail/WhatsApp — but this doesn't work reliably on every phone or browser (Chrome's file-sharing support varies), so it's offered as an extra option, not the main path. If it fails, it automatically falls back to the regular Save above.

Same-Day Snapshot

No snapshot yet.
The app quietly saves a same-day snapshot automatically, and right before every Import — so a bad import or an accidental mistake can be undone. This does not protect against clearing browser data or reinstalling — only Export (above) is a true off-device backup.

Reset App

Wipes everything on this device — sessions, fuel log, expenses, loan, personal trips, and the snapshot. Useful for starting fresh or troubleshooting. This cannot be undone — export a backup first if there's anything you want to keep.
